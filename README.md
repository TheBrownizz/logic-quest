# Logic Quest

Logic Quest הוא משחק לימוד בעברית (ממשק מימין לשמאל) שמלמד לוגיקה דיגיטלית ומיתוג דרך חדרי חידות, שערים לוגיים ומפת עולם. השחקן מתקדם בין שלבים, פותר חדרים עם טענות נכונות ושקריות ומקבל משוב על הנימוק שלו.

## הרצה מקומית

```bash
npm install
npm run dev
```

## בדיקות

```bash
npm test        # בדיקות יחידה ותוכן (Vitest)
npm run e2e     # בדיקות קצה-לקצה (Playwright)
```

בדיקות ה-e2e לא רצות ב-CI: הדפדפנים של Playwright לא מותקנים שם, והתקנתם איטית. הריצו אותן מקומית לפני דחיפה.

## הוספת תוכן

התוכן נמצא בתיקייה `src/content/switching/`. אחרי כל שינוי, הוולידטור ובדיקות התוכן חייבים לעבור (`npm test`).

כללים:

- שדה `compute` חובה בחדרי מספרים.
- לפחות 40% מהטענות שקריות.
- הנימוקים לא מצהירים על פסק הדין (נכון/לא נכון).
- שמות הכניסות והיציאות (IN/OUT) מסודרים לפי סדר אלף-בית.
- לשער יש לכל היותר 2 כניסות.
- המקור הוא `סילבוס: <נושא>`.
- הטקסט מקורי, לא מועתק.

## פריסה

```bash
git push origin main
```

לאחר הדחיפה הראשונה, ב-GitHub: Settings → Pages, ובשדה Source בוחרים "GitHub Actions". מכאן כל דחיפה ל-`main` מריצה בדיקות, בונה ופורסת אוטומטית.

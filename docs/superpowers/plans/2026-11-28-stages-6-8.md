# Stages 6–8 and Mock Exam Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add the sequential-logic stages 6 (Latches/FF), 7 (FSM analysis) and 8 (FSM design and reduction), each with lessons, rooms and cards, plus a boss mock exam.

**Architecture:**
- Pure logic lives in `src/logic/{sequential,fsm,waveform}.ts`.
- New `LabPuzzle` kinds each come with a pure checker, a validator extension and a room UI.
- An SVG schematic generator draws circuits from a netlist.
- Three new lesson widgets are added to the existing registry, with types pinned before parallel work.
- The boss is a separate `world.boss` bank of `ExamQuestion`s, played in an ExamScreen. Results are stored in `SaveData.exams`.

**Tech Stack:** existing. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-11-28-stages-6-8-design.md` (Hebrew; 6.7 binding)

## Global Constraints
- Course conventions:
  - in state tables, the first state variable is the MSB and the input is the LSB;
  - D flip-flops trigger on the rising edge;
  - states are named S0, S1, …;
  - simplified equations are written in SOP.
- Every answer is computed by `src/logic`, never typed by hand.
- All existing content rules apply:
  - ≥40% of claims are false;
  - reasons state no verdict;
  - wrong options have plausible distractors;
  - formulas go in `ltr()`;
  - wording is original;
  - the source is `"סילבוס: <topic>"`;
  - gates have ≤2 inputs in circuit rooms.
- Each stage has ≥6 rooms, ≥15 cards and 2–3 lessons. Lessons follow the existing engine rules, use `widgetStep()`, and are gated like stages 1–5.
- `fsm-equations`: the encoding is given. The optimal star is awarded when the total literals across all equations are ≤ the QM minimum total with don't-cares.
- `state-reduce`: completely specified machines only.
- `waveform`: a discrete half-cycle grid with the initial Q given, and only well-defined cases.
- Boss:
  - 16 questions, 4 per topic;
  - an exam takes one question per topic, picked by a seed;
  - scoring: א' 10 (all or nothing), ב' 5 + 5, ג' 5;
  - short mode: topic 4 plus one random topic, 60 minutes, scaled to 100;
  - ≥80 shows "מוכן למבחן";
  - it unlocks by the 60% rule on stage 8 and is exempt from lesson gating.
- `SaveData.exams = { attempts: {at:number, score:number, perTopic:number[]}[] }`, optional, defaulting to `{attempts: []}`, keeping the last 20. If `src/game/merge.ts` exists when you merge, add the rule "union by `at`".
- Hebrew UI, theme tokens only, keyboard accessible, works at 400px (the exam screen may require ≥768px).

## Review Focus
1. JK with J=K=1 toggles at an edge. An SR forbidden input must never appear in content (the validator rejects it in waveform and table puzzles).
2. A student's `fsm-equations` answer uses don't-cares differently from QM but is equivalent. It must be accepted.
3. A state-reduce answer with the same partition but different group order or naming is accepted.
4. If the exam timer runs out mid-question, the score uses what has been answered so far. A reload mid-exam discards the attempt cleanly.
5. Stages 6–8 lock and unlock correctly from a v1-plus-lessons save.

### Task 1 (sequential): logic core
- `sequential.ts`: `FFType = 'D'|'T'|'JK'|'SR'`; `nextState(t, q, inp)`; `excitation(t, q, qNext)` → inputs with 'x'; `isForbidden('SR', inp)`.
- `fsm.ts`:
  - `Fsm`, `StateTable` (rows ordered state-MSB…input-LSB);
  - `stateTable(fsm)`;
  - `fromEquations({ next: Record<var, (v) => Bit>, out })`;
  - `dInputs(table)` → per D: `{minterms, dontCares}`;
  - `isMoore(table)`;
  - `reduceStates(table)` → a partition;
  - `canUseSingleFlipFlop(table)`.
- `waveform.ts`: `simulateWave(kind: 'latch-D'|'latch-SR'|'ff-D'|'ff-T'|'ff-JK', clk: Bit[], inputs: Record<string, Bit[]>, q0: Bit)` → Bit[], which throws on a forbidden or race case.
- **Tests:** truth-table exhaustive checks for each FF type; the two sample-exam FSMs reproduced (the moed-B 4-state table and the moed-A equations, giving the expected tables); reduction on a textbook example.
